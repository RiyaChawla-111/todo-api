# Tiny TODO API — REST API Documentation Demo

This project is a simple TODO API created for learning API documentation as a technical writer.  
It includes:

- OpenAPI 3.0 specification (`openapi.yaml`)
- Express.js API implementation (`app.js`)
- Postman collection
- Swagger UI documentation (`docs/` folder)
- Example request/response samples
